# Intersectional Fairness Project

This project aims to explore and implement methods for achieving intersectional fairness in machine learning models, and still updating now.

## Directory Structure

- `config/`: Configuration files
- `data/`: Data storage
  - `raw/`: Raw data files
  - `processed/`: Processed data files
  - `generated/`: Generated data files for causal modeling
- `src/`: Source code
  - `utils/`: Utility functions
  - `detection/`: Sensitivity detection
  - `df_training/`: Demographic fairness training
  - `causal/`: Causal modeling
  - `models/`: Machine learning models
- `notebooks/`: Jupyter notebooks for analysis and visualization
- `experiments/`: Experiment scripts
- `results/`: Experiment results, plots, and models

## Getting Started

1. Clone the repository
2. Set up the environment using `environment.yml` or `requirements.txt`
3. Run the experiments using the scripts in the `experiments/` directory
4. Analyze the results using the notebooks in the `notebooks/` directory
